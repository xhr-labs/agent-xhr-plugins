# Deactivate Employee Help

## Intent: deactivate-employee-help
### User request patterns
- deactivate an employee temporarily
- reactivate a deactivated employee
- explain deactivate versus terminate
- explain why the deactivate action is unavailable

### Retrieval tags
- employee
- deactivate
- reactivate
- lifecycle
- direct-answer

### Answer objective
Explain temporary employee deactivation and distinguish it from termination and archive.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
1. Open [People]({{people_url}}).
2. Find the employee and open their lifecycle actions.
3. Select **Deactivate Employee** and confirm.
4. Use **Reactivate** when the employee should return to active status.

Deactivation is temporary and does not record the employee's exit. Use **Terminate** when HR needs an exit date, remaining time-off review, or settlement details. Use **Archive** for an eligible terminal record that should leave active People views.

If the action is unavailable, check the employee's current state, self-action restrictions, and the user's employee lifecycle permissions.
