# Allocation Management Skill Tree

Use this guide to navigate Allocation Management product-help leaves. Allocation Management plans employee effort against projects and compares the plan with capacity and imported actual work.

## Available leaves

- skills/allocation_management/allocation_overview_help/SKILL.md — Explain the product, menus, roles, and planning concepts.

## Suggested navigation
- Use `allocation_setup_help` for HR or Admin setup, the five employee/department custom fields, employee values, Allocation data refresh, capacity prerequisites, and setup troubleshooting.
- Use `create_allocation_custom_fields` when an Admin asks to create the five Allocation custom-field definitions. Preview first, then require confirmation before writing.
- Use `allocation_overview_help` for general resource planning, menus, audiences, and app purpose questions.
- Use `monthly_allocations_help` for allocation list, allocation percent, project rows, warnings, period locks, and inline row guidance.
- Use `project_allocation_reports_help` for project reports, allocation history, dashboard filters, line views, and resource summaries.
- Use `timesheet_variance_help` for planned allocation versus actual timesheet comparison and missing actuals.
- Use `allocation_integrations_help` for YouTrack, Workbench, X-HR Platform, Attendance Tracking, and synchronization guidance.
- Use `dashboard` to fetch and present the Summary, Utilization, Allocation by Line, and Timesheet dashboard sections for a reporting period.
- Use `allocation_troubleshooting_help` for symptoms that cross setup, permissions, employee data, project state, period locks, calculations, reports, or integrations.
- Use `allocation_report_chart_glossary` for questions such as how utilization is calculated, what internal or borrowed resources mean, and how to interpret any Allocation report chart.
- Use `find_overallocated_employees` for direct questions about who is currently over capacity or overloaded.
