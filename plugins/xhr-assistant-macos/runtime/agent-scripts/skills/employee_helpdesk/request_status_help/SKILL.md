# Employee Request Status Help

## Intent: employee-helpdesk-status-help
### User request patterns
- explain Employee Helpdesk request statuses
- what does action required mean
- what happens when HR asks for more information
- how do I follow up on my HR request
- what happens after HR resolves a request

### Retrieval tags
- employee-helpdesk
- status
- action-required
- conversation
- direct-answer

### Answer objective
Explain status meaning and the employee's next action.

### Instructions
- Answer directly without calling executable tools.
- Distinguish public messages from HR-only internal notes.

### Direct answer
The request status shows where the case is in the HR workflow. When HR moves it to **Waiting for employee**, the employee should read the public explanation and reply with the requested information or attachment. Public conversation updates are visible to the employee; HR internal notes are not. A resolved request has an HR outcome, while a closed request is no longer editable or open for further discussion.
