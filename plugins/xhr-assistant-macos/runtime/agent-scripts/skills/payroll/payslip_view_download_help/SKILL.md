# Payslip View and Download Help

## Intent: payroll-payslip-view-download-help
### User request patterns
- view my payslip
- download my payslip PDF
- retry a payslip download
- explain why a payslip is still processing
- explain why I cannot view another employee payslip

### Retrieval tags
- payroll
- payslip
- pdf
- download
- direct-answer

### Answer objective
Explain self-service payslip preview and download behavior.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Open [My Profile -> Compensation -> My Earnings]({{my_earnings_url}}), then select **View** or **Download** on the relevant pay record.

X-HR prepares the payslip PDF and opens it in the document viewer or downloads it when ready. If generation takes too long or fails, retry the action from the same row.

Payslip preview and download are available only for the authenticated employee's own payslips.
