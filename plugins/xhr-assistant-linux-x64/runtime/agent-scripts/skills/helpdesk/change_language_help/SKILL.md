# Language & Region Help

Use this direct-answer leaf when the user asks how to manage language, timezone, or regional preferences.

### Answer objective
Answer directly with the documented Language & Region guidance that matches the requested preference.

### Instructions
- Answer directly in text using the guidance below.
- Do not call executable tools for this skill.

### Direct answer
1. Open [Language & Region]({{account_language_region_url}}), or select it from the avatar menu.
2. Choose the language, timezone, or regional preference requested by the user from the available options.
3. Save the changes when the page presents a save action.

For language changes only, the user can alternatively ask the Smart Agent directly, for example: "Switch platform to English." Do not suggest that the Smart Agent can change timezone unless that action is explicitly supported.

**Prerequisites**
- No special permissions are required. Users can update their own Language & Region preferences.

**Common Errors and Solutions**
- **Preference not updating**: Try refreshing the page or logging out and back in.
- **Option not available**: The selected language, timezone, or regional option might not be supported yet — contact **Support** if needed.
