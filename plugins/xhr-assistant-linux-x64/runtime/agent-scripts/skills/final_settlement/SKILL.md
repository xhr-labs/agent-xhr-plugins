## Suggested navigation
- Use `final_settlement_overview_help` for app purpose and settlement workflow questions.
- Use `final_settlement_setup_help` when the user asks how to set up EOS, end-of-service settlement, Final Settlement, Offboarding settlement items, EOSG schemes, or payroll handoff readiness.
- Use `final_settlement_permissions_help` for app access and permission questions.
- Do not use this domain when an employee asks how much their end-of-service benefit, gratuity, or settlement would be for a planned resignation date. That is an executable Payroll leaf: read `skills/payroll/get_my_end_of_service_estimate/SKILL.md`.
