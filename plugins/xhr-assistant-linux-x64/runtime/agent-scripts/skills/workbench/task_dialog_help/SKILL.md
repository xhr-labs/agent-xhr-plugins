Explain the improved task detail experience and when to use it.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Open [Workbench -> Spaces]({{workbench_spaces_url}}) and select the project task.

Workbench task dialogs provide a richer task detail workspace. Depending on the project setup, users can edit task fields, review linked tasks, switch task panels or tabs, and use a resizable sidebar or full-screen layout for more context.

Lumi can be available from task flows to draft or refine task descriptions. Use the create-task or task-description skill only when the user wants to generate or create actual task content.
