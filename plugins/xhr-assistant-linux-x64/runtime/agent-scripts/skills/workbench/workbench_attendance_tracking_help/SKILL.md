### Instructions

### Direct answer
Open [Workbench]({{workbench_url}}) for project work or [Attendance Tracking]({{attendance_url}}) for attendance records.

Workbench tracks project/task work context, while Attendance Tracking captures attendance and timesheet activity. Cross-app comparison helps teams understand whether project work and attendance records align.

For resource planning and variance reporting, Allocation Management is usually the better domain because it compares planned allocation with timesheet or attendance activity where integrations are configured.
