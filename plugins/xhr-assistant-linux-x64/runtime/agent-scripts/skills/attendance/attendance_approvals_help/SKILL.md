### Direct answer
Open [Timesheet Approvals]({{attendance_approvals_url}}). Pending items can also be reviewed from [Reports]({{attendance_reports_url}}) using the Waiting for approval view.

Attendance approvals let authorized managers review submitted timesheets and approve or reject them. The approvals page includes pending timesheets and history; Reports provides a broader approved or waiting-for-approval view and detail context.

Only pending entries can usually be approved or rejected. If a request is missing, check its status, the reviewer's authorized reporting scope, and the employee/date filters before assuming the data is absent. Approve All can remain in progress while approvals and overtime are reconciled; do not submit a duplicate bulk action while that operation is processing. If the user asks to approve or reject a specific request, first identify the request clearly and then use the relevant attendance approval skill.
