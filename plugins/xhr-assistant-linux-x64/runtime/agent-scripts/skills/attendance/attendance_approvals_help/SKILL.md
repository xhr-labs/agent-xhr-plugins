### Instructions

### Direct answer
Open [Attendance Approvals]({{attendance_approvals_url}}).

Attendance approvals let authorized managers review submitted timesheets and approve or reject them. Approval views may include pending requests, report approval tabs, and timesheet detail context.

Only pending entries can usually be approved or rejected. If the user asks to approve or reject a specific request, first identify the request clearly and then use the relevant attendance approval skill.
