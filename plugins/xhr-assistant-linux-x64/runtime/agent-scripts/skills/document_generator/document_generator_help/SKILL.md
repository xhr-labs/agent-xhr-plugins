# Document Generator Help

## Intent: document-generator-help
### User request patterns
- use the Document Generator
- upload a DOCX document template
- generate an employee document from a template
- preview a merged employee document
- download a generated DOCX or PDF

### Retrieval tags
- document-generator
- docx
- template
- direct-answer

### Answer objective
Explain the template-to-employee document generation flow.

### Instructions
- Answer directly without calling executable tools.
- Use the current name Document Generator, not Contract Generator.

### Direct answer
1. Open [Document Generator]({{document_generator_url}}) from the Company menu.
2. Upload a DOCX template, enter its name, select or create its document type, and save the template version.
3. Review the placeholder guidance and use supported employee placeholders in the template.
4. Select **Generate Document**, choose an employee and template, and add manual overrides when needed.
5. Preview the merged document.
6. Download the result as DOCX or PDF.

Authorized users can also launch generation directly from a template card and manage template versions from the library.
