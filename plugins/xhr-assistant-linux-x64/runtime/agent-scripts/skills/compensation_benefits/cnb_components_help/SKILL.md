### Direct answer
Open [C&B Components]({{cnb_components_url}}).

C&B components are reusable configuration units in Compensation & Benefits. They help HR define repeatable compensation or benefits structures that can be referenced by package groups or connected processes.

Use C&B components when the organization wants consistent setup across employee groups, reward structures, or payroll-connected compensation data.
