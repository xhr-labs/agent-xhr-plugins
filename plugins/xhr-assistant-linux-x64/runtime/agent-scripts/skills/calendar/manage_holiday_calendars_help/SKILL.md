### Direct answer
## How to manage calendar holiday

Follow these steps:

1. Go to [Workspace -> Holiday Calendars]({{holiday_calendars_url}}).
2. The page will display the calendar for the current year by default. Click on the calendar entry to see all public holidays for that year. From there, you can update, delete or add new holidays as you wish. If you need to work with a different year, select or create the relevant year’s calendar from the list.

## Notes
- There’s an option for each calendar year to allow applying common holidays to all locations or you can set it up per location. If you want to manage per location, untick it and it will show per location for updating data.
