### Answer objective

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Payroll admins manage statutory scheme setup in [Payroll -> Statutory Schemes]({{payroll_statutory_url}}) where the statutory module is available. A statutory scheme can include scheme details, contribution types, statutory programs, eligibility rules, calculation bases, output lines, and assigned employees.

For an individual employee, open the employee profile and select **Compliance & Taxation**. When Payroll is installed and schemes are available for that employee, the statutory-scheme section appears there.

Authorized admins can add or remove enrollments. Other permitted users may see assigned schemes as read-only labels. Availability depends on the employee, work location, Payroll installation, scheme eligibility, and access permissions.
