# My Tasks Help

## Intent: workbench-my-tasks-help
### User request patterns
- show my Workbench tasks
- where are my assigned tasks
- view tasks assigned to me
- see my tasks across projects
- explain My Tasks in Workbench

### Retrieval tags
- workbench
- my-tasks
- assigned-tasks
- project-management
- direct-answer

### Answer objective
Explain the consolidated assigned-task view.

### Instructions
- Answer directly without calling executable tools unless the user asks for live task data.

### Direct answer
**My Tasks** gives the current user a consolidated view of tasks assigned to them across projects they can access. It is useful when the user wants one queue instead of opening each project separately.

If the user wants live task records, use the Workbench task-listing skill. If they only ask where the feature is or how it works, answer directly.
