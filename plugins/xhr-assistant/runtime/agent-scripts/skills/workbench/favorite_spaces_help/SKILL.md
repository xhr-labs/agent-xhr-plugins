# Favorite Spaces Help

## Intent: workbench-favorite-spaces-help
### User request patterns

- remove a favorite space

### Retrieval tags

### Answer objective
Explain favorite spaces as a navigation shortcut.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Favorite spaces let users keep frequently used Workbench spaces easy to find from the sidebar or navigation area. This is a personal navigation shortcut and does not change the underlying project, wiki, or space permissions.

If a favorite disappears or cannot be opened, check whether the space still exists and whether the user still has access.
