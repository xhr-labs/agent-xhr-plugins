### Answer objective
Explain appointment schedules and where booking-specific actions belong.

### Instructions
- Answer directly for help questions.
- Use the calendar booking leaf only when the user asks to make or manage a concrete booking.

### Direct answer
Open [Appointment Schedules]({{calendar_appointment_schedules_url}}).

Appointment schedules let users publish availability for others to book time. Schedulers can configure the schedule, availability, and related settings where they have permission.

For external or shared booking scenarios, use the schedule's share link if available. For a concrete booking request, use the calendar booking flow with the target schedule, attendee, and time details.
