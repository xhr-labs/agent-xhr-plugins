### Instructions

### Direct answer
Open [Calendar Integrations]({{calendar_integration_url}}).

Calendar can support Google Calendar integration where the tenant and user have the integration enabled. The integration can include configuration for whether invites are sent through Google when appointments or events are created.

If invites are not being sent, check integration connection status, schedule settings, user permissions, and whether send-invite behavior is enabled for that flow.
