# Calendar Share Links Help

## Intent: calendar-share-links-help

### Answer objective
Explain share links for appointment scheduling.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Open [Appointment Schedules]({{calendar_appointment_schedules_url}}) to manage share links.

Appointment schedule share links let a scheduler share booking availability with another person. The recipient can use the link to choose an available time according to the schedule configuration.

If the link is unavailable or does not work, check whether the schedule is active, whether sharing is enabled, and whether the user has permission to manage that schedule.
