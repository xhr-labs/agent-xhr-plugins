# Maternity Leave Help

## Intent: timeoff-maternity-leave-help
### User request patterns
- configure maternity leave
- request maternity leave
- explain maternity leave in Time Off
- add maternity leave type
- manage maternity leave policy

### Retrieval tags

### Answer objective
Explain maternity leave as a supported leave type or policy scenario.

### Instructions
- Answer directly without calling executable tools.
- Avoid legal advice; direct policy-specific questions to HR policy owners.

### Direct answer
Maternity leave can be managed in Time Off as a leave type or policy scenario where enabled. HR admins configure the relevant leave type or policy, and eligible employees request maternity leave through the normal time-off request flow.

Rules such as entitlement, documentation, duration, pay treatment, and eligibility are company- and jurisdiction-specific, so users should confirm the final policy with HR.
