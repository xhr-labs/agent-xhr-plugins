# Time Off Carryover Help

## Intent: timeoff-carryover-help
### User request patterns
- configure leave carry-over
- carry unused leave to next year
- explain time off carry-over
- set carry-over limits
- update carry-over in a time off policy

### Retrieval tags

### Answer objective
Explain carry-over as part of time-off policy setup.

### Instructions
- Answer directly without calling executable tools unless the user asks Lumi to generate a policy setup.

### Direct answer
Carry-over controls whether unused leave can move into a later period and under what limits. Configure it in the relevant Time Off policy when the organization allows employees to keep some unused balance.

Carry-over results depend on the policy's allowance, proration, accrual period, effective dates, and backend recalculation rules.
