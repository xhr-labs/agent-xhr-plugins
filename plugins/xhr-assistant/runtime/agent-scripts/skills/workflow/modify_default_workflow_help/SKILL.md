### Direct answer
By default, you cannot modify a system default workflow.  
However, you can **duplicate** it and customize your own version.

To do this:
1. Click **Duplicate** on the default workflow  
2. Update the copied workflow as needed  
3. Activate it to start using your customized version  

Once activated, your custom workflow will run independently of the default one.
