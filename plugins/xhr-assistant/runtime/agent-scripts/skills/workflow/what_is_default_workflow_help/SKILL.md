### Direct answer
A default workflow is automatically created by an app when you install it from the App Store, or pre-installed by the system.

These workflows provide ready-to-use automation for common scenarios.

**Examples:**
- **Time-off request workflow** - installed with the Time Off app  
- **Attendance tracking workflow** - installed with the Attendance Tracking app
