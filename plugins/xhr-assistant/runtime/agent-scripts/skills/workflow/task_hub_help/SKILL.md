# Task Hub Help

## Intent: workflow-task-hub-help
### User request patterns
- open my assigned workflow tasks
- complete a task in Task Hub
- fill a form from Task Hub
- upload a document for a workflow task
- update emergency contact from a task
- explain why a completed task is read only

### Retrieval tags
- workflow
- task-hub
- assigned-task
- form-task
- direct-answer

### Answer objective
Explain how users find and complete workflow-assigned work.

### Instructions
- Answer directly without calling executable tools.
- Do not confuse Task Hub with Workbench project tasks.

### Direct answer
Task Hub contains work assigned by HR workflows. Open the task or its direct link, review the task details, and use the available action.

Supported task experiences include acknowledging a policy, uploading a document, updating employee contact or emergency-contact details, completing a form, onboarding, and assigned review steps. Only tasks in an actionable status can be edited or completed. Completed task details are read-only and may show the submitted form or document reference.
