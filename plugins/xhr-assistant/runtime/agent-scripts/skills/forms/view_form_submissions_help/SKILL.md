# View Form Submissions Help

## Intent: forms-view-form-submissions-help
### User request patterns
- view submitted form data
- open form submission details
- check review form progress
- export a form submission report to PDF
- create an employee from an onboarding submission

### Retrieval tags
- forms
- submissions
- reports
- pdf-export
- onboarding
- direct-answer

### Answer objective
Explain the submissions tab, detail views, report export, and onboarding handoff.

### Instructions
- Answer directly without calling executable tools.
- Distinguish normal table submissions from report-style review submissions.
- Treat the published version as the source for Submitted Data review; do not tell users that draft-only fields will appear there.
- Explain that the backend supplies table/report grouping and progress metadata.

### Direct answer
1. Open [Forms]({{forms_url}}) and select **Submitted Data**, or open the published form and switch to **Submissions**.
2. Select a row to view its read-only details.
3. Normal submissions display grouped answers. Review/report submissions also show subject employee context, workflow progress, completed review steps, and incomplete steps when returned by the service.
4. Report-style submissions can be exported with **Export PDF**. The PDF is generated by the backend.
5. For a public onboarding submission that is not linked to an employee, authorized HR users can select **Add employee** to open the employee form with recognized answers prefilled.

If metadata or columns appear blank, the service response and exact column keys are the source of truth. The frontend does not merge review rows or infer missing report groups locally.
