# Manage Form Versions Help

## Intent: forms-manage-form-versions-help
### User request patterns
- edit a published form
- create a draft version of a form
- publish a form version
- archive a form
- unpublish a public form

### Retrieval tags
- forms
- versions
- draft
- archive
- unpublish
- direct-answer

### Answer objective
Explain status-aware form editing and lifecycle actions.

### Instructions
- Answer directly without calling executable tools.
- Do not imply archived forms are permanently deleted.

### Direct answer
- Draft forms can be edited and published.
- To change a published form, open **Manage versions** and create or edit the latest draft version. Publishing that draft makes it the active version.
- Use **Unpublish** in public sharing settings when the public link should stop accepting access.
- Use **Archive** when the form is no longer operational. X-HR asks for confirmation and removes normal edit/publish actions from archived forms.
- While a publish, archive, or version action is processing, wait for it to finish before starting another action.
