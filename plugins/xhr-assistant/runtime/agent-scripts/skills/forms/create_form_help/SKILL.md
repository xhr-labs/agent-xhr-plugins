# Create Form Help

## Intent: forms-create-form-help
### User request patterns
- create a form in X-HR
- build a new employee form
- add fields and sections to a form
- configure required fields in a form
- preview a form before publishing

### Retrieval tags
- forms
- form-builder
- fields
- validation
- direct-answer

### Answer objective
Explain the current form-builder flow and the main configuration options.

### Instructions
- Answer directly without calling executable tools.
- Keep general forms separate from onboarding and review forms.

### Direct answer
1. Open [Forms]({{forms_url}}) and select **Add new form**.
2. Choose the form type, then enter its name, description, and work location when applicable.
3. Add fields from the builder toolkit. Supported options include text, long text, email, full name, date, choices, matrix rating, sections, and dividers.
4. Organize fields into groups or steps when the form needs sections or assigned stages.
5. Configure labels, options, validation, and whether supported fields are required.
6. Use **Preview** to check layout and validation before saving.
7. Save and publish when the form is ready.

System-required onboarding attributes cannot be made optional. Section and divider elements are layout content and do not collect answers.
