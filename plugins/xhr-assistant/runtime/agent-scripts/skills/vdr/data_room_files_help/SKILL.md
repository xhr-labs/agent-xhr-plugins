# Data Room Files Help

## Intent: vdr-data-room-files-help

### Answer objective
Explain file and folder operations in data rooms.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
VDR file management supports organizing documents into data rooms and folders. Users with the right role can upload files, create folders, rename or delete items, and preview documents where supported.

File preview may fetch the document only when the user opens it. This helps keep list loading lighter while still allowing secure document review.
