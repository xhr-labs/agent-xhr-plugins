# Data Room Management Help

## Intent: vdr-data-room-management-help

### Answer objective
Explain data-room lifecycle management at a product level.

### Instructions
- Answer directly without calling executable tools unless the user asks for live data room records.

### Direct answer
Virtual Data Room management lets authorized users create and maintain secure data rooms for controlled document sharing. Data-room actions can include create, edit, activate, close, delete, and open detail pages depending on status and permission.

Use the VDR list or detail view to manage rooms. If the user asks for live room records, use the VDR listing skill.
