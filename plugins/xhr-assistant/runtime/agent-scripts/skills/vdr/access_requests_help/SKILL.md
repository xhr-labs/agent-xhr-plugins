# VDR Access Requests Help

## Intent: vdr-access-requests-help
### User request patterns
- approve data room access requests
- reject a VDR access request
- view pending access requests
- explain data room access request workflow
- manage stakeholder access requests

### Retrieval tags

### Answer objective
Explain access request review and decision behavior.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Open [Virtual Data Room]({{vdr_data_rooms_url}}), select the data room, and open its access requests.

VDR access requests let authorized data-room users review who is asking for access and decide whether to approve or reject the request. Request views can include pending lists, detail sidebars, and waiting-for-approval sections.

Only users with the required data-room role can approve or reject requests. The decision affects access to that data room, not general company access.
