# VDR Activity Analytics Help

## Intent: vdr-activity-analytics-help
### User request patterns
- view data room activity logs
- check who downloaded a file
- review VDR analytics
- explain data room audit history
- show file view activity

### Retrieval tags
- vdr
- activity-logs

### Answer objective
Explain activity and analytics surfaces, and route live log requests to executable VDR leaves.

### Instructions
- Answer directly for product-help questions.
- Use VDR audit log leaves when the user asks for live audit log data.

### Direct answer
VDR activity and analytics help teams understand how a data room is being used. Activity logs can show events such as file views, downloads, stakeholder activity, folder activity, and actions triggered by contributors.

Analytics provide a higher-level summary of engagement. If the user asks for actual audit log records, use the VDR audit log skill instead of answering from memory.
