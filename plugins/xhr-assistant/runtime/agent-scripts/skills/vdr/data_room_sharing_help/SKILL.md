# Data Room Sharing Help

## Intent: vdr-data-room-sharing-help
### User request patterns
- share a data room
- add internal contributors to a data room
- invite external stakeholders to a data room
- change a data room contributor role
- explain data room visibility

### Retrieval tags
- vdr
- sharing
- contributors
- stakeholders
- roles
- direct-answer

### Answer objective
Explain internal and external sharing surfaces and role-aware access.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Open [Virtual Data Room]({{vdr_data_rooms_url}}) and select the data room to manage sharing.

Data rooms can be shared with internal contributors and external stakeholders where the user's role allows it. Internal roles can control who owns, contributes to, or views the data room. External stakeholder sharing controls who outside the internal team can access the room.

Sharing actions are permission-aware. If a user cannot share or change roles, check their contributor role and the data room's visibility or access settings.
