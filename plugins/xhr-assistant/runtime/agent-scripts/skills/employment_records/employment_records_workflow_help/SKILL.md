### Answer objective
Explain how Employment Records can participate in workflow and approval processes.

### Instructions
- Answer directly without calling executable tools.
- Refer executable workflow actions to the Workflow domain when the user asks to create or run a workflow.

### Direct answer
Employment Records can integrate with Workflow so contract or employee-change records can appear in approval or task-driven processes. This helps HR route record changes through the right reviewers while keeping the record context available.

Use Employment Records for the contract/change content. Use the Workflow domain for configuring triggers, approval steps, tasks, and notifications around those records.
