# Employment Record Activity Logs Help

### Answer objective
Explain the activity timeline and how users should interpret it.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Employment Records activity logs show the history of important actions on a contract or change record. The timeline can include record updates, attachment activity, status changes, and other localized activity captions.

Use the activity timeline when HR needs to understand what happened to a record, who triggered an action, and when the event occurred. Visibility depends on record access permissions.
