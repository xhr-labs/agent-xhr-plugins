# Company Decisions Help

### Answer objective
Explain the company decisions area and permission-aware visibility.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
The **Company Decisions** area in Employment Records is used for decision records that should be managed separately from ordinary employee profile edits. Access to lists, details, and actions is permission-aware.

If a user cannot see or edit company decisions, check whether the app is installed for the tenant and whether the user has the required Employment Records data-block permissions.
