# Employment Contracts Help

### Answer objective
Explain the contract management flow without executing record changes.

### Instructions
- Answer directly without calling executable tools.
- Keep Employment Records contracts separate from general employee profile editing.

### Direct answer
Employment Records supports contract-style records for employee employment changes. Authorized users can create or edit contract records through a guided form, review entered job and compensation information, and open the contract detail page for the final record context.

The contract flow can include step navigation, validation, review copy, attachments, activity history, and permission-aware actions depending on the user's access.
