### Answer objective
Explain how documents support contract and change records.

### Instructions
- Answer directly without calling executable tools.
- Mention managed document-type behavior cautiously.

### Direct answer
Open [Contracts]({{ccd_contracts_url}}) and select the relevant record.

Employment Records can attach documents to contract or change records so HR can keep supporting files with the record context. The detail view may include file tables, preview actions, and upload or update behavior depending on permission and record state.

Document type choices can be filtered by category, and system-generated document types may be protected from deletion where the product needs to preserve governed records.
