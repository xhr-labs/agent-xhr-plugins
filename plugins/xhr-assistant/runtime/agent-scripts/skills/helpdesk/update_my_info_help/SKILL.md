### Direct answer
**Instructions:**
1. Go to [My Profile]({{my_profile_url}})
2. Select the desired profile section (Personal, Job, Compensation etc)
3. Update required fields directly in-line or select “Edit” from the available options 

**Prerequisites:** Edit permissions for own profile

**Common Errors & Solutions:**
"Unable to update field" → Check or request for your admin to update the field as it might be sensitive information (salary, name, job details etc)

**Follow-up examples:** Remind users to always keep their profiles updated in case of emergencies (emergency contact, address etc)
