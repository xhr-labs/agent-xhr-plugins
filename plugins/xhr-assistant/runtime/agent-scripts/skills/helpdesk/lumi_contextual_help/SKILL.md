# Lumi Contextual Help

## Intent: helpdesk-lumi-contextual-help
### User request patterns

### Answer objective
Explain host-controlled contextual chat and layout behavior.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Product areas can open Lumi with a suggested prompt and relevant setup context. When context is active, Lumi shows a dismissible context badge and uses that context to guide subsequent responses until the badge is cleared.

On desktop, Lumi opens in the persistent, resizable right sidebar and remains available while platform dialogs are open. On mobile, Lumi uses a compact popover experience.
