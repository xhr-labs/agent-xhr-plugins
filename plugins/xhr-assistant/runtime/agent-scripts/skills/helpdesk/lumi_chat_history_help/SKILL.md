# Lumi Chat History Help

## Intent: helpdesk-lumi-chat-history-help
### User request patterns
- reopen a previous Lumi conversation
- start a new Lumi chat
- rename a Lumi chat
- pin or unpin a Lumi conversation
- delete a Lumi chat

### Retrieval tags
- helpdesk
- lumi
- chat-history
- sessions
- direct-answer

### Answer objective
Explain server-backed Lumi conversation history and session actions.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Open Lumi and use the conversation selector in the chat header.

- Select a conversation to replay it and continue in the same session.
- Select **New chat** to start without the previous conversation.
- Use a conversation's action menu to rename, pin, unpin, or delete it.
- Pinned conversations appear separately from recent conversations.

Deleting the active conversation requires confirmation and clears it from the current chat only after deletion succeeds.
