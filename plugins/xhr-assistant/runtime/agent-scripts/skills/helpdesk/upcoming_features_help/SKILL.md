### Direct answer
Here’s a quick overview of what’s planned for the X-HR platform:

- ✍️ **E-Sign Documents** — planned for **Q3**
- 💸 **Expense Management** — planned for **Q3**
- 🧾 **Asset Management** — planned for **Q3**
- 🎯 **Hiring App** — planned for **Q4**

**Do I need to set anything up in advance?**

No. These features will be rolled out automatically once they’re released.  
You’ll be notified through in-platform updates and email announcements.

**How can I prepare my team?**

To get the most value as soon as these features go live, we recommend:

- Reviewing and organizing **employee roles and permissions**
- Ensuring your **company structure and employee data** are up to date

This helps your team start using new apps (such as time-off, tasks, or hiring) immediately when they become available.

**How can I track updates or request new features?**

- Visit the [App Store]({{app_store_url}}) to see upcoming and newly released apps
- Use the **Request / Suggest** option to share ideas or request features directly with us
- We will also send announcement when releasing new apps
