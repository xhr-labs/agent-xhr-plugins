# Technical Skills and API Help

## Intent: helpdesk-technical-skills-and-api-help

### Answer objective
Explain the no-code product experience and developer extension options conservatively.

### Instructions
- Answer directly without calling executable tools.
- Do not promise public API or custom-app publishing availability without checking the current developer or App Store experience.

### Direct answer
HR teams do not need coding skills for normal X-HR use. They can manage employees, build forms, configure workflows, maintain organization structures, and use installed apps through product interfaces.

Developers can use supported integration, SDK, and API surfaces where they are available for the company and environment. For a specific integration or custom-app requirement, check the current [App Store]({{app_store_url}}) or developer documentation before assuming an endpoint or publishing flow is public.
