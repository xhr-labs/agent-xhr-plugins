# Change Language Help

Use this direct-answer leaf when the user asks about change language help.

# Intent Map

## Intent: helpdesk-change-language-help
### User request patterns
- How to change or switch the platform language?

### Retrieval tags
- helpdesk
- language
- localization
- direct-answer

### Answer objective
Answer directly with the documented HelpDesk guidance.

### Instructions
- Answer directly in text using the guidance below.
- Do not call executable tools for this skill.

### Direct answer
1. Click on the **Avatar** icon on the top right navigation.
2. Select **Language & Regions** from the sub-menu.
3. Choose your preferred language from the available options.
4. Alternative option:
   - You can also ask the Smart Agent directly by saying: "Switch platform to English" (or your desired language).

**Prerequisites**
- No special permissions are required. All users can update their own language preferences.

**Common Errors and Solutions**
- **Language not updating**: Try refreshing the page or logging out and back in.
- **Option not available**: Language support might not be available yet for your selected language — contact **Support** if needed.
