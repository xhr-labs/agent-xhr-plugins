# Final Settlement Permissions Help

### Answer objective
Explain app permission gating for Final Settlement.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Final Settlement access is controlled through the app's permission setup. A user must have the app available to their tenant and the required app access or data-block permission to view or manage settlement information.

If a user cannot see the app, check whether Final Settlement is installed or enabled, whether the user belongs to an allowed access group, and whether their role has the required read or write permission.
