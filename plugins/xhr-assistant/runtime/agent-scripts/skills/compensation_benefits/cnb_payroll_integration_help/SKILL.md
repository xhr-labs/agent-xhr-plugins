# C&B Payroll Integration Help

## Intent: compensation-benefits-payroll-integration-help

### Answer objective
Explain the high-level relationship between C&B setup and Payroll.

### Instructions
- Answer directly without calling executable tools.
- Refer pay component generation to the Payroll domain when the user wants a payroll setup payload.

### Direct answer
Compensation & Benefits provides reward, package, and component structures that can inform payroll setup and pay data. Payroll remains the system area for pay components, statutory/tax setup, pay runs, payslips, and compliance exports.

Use C&B to define the compensation and benefits structure. Use Payroll to calculate, review, approve, and export payroll results.
