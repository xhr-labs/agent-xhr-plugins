### Direct answer
Open [Finance Hub]({{finance_url}}) and switch to the category view.

Finance Hub categories classify income and expense data so financial activity can be reviewed consistently. Users with permission can create, edit, delete, or review categories depending on the app setup.

The category matrix or category table helps finance users inspect category-level values and compare financial information across periods or views.
