### Answer objective
Explain privacy-safe HR reporting and its operational uses.

### Instructions
- Answer directly without calling executable tools.
- Use the report tool for a live tenant-scoped report when requested.

### Direct answer
Employee Helpdesk reports give HR a monthly, privacy-safe view of request volume and status, SLA performance and ageing, and workload or assignment distribution. Filters can narrow the view by request type, status, priority, department, location, queue, assignee, SLA outcome, or ageing bucket. Report access is separate from request-detail access.
