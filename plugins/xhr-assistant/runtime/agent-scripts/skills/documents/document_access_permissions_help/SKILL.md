### Direct answer
**Instructions:**
1. Go to [Documents]({{documents_url}})
2. Find and select the document
3. Click on the available options and select “ Edit Details & Access Permissions”
4. Check “Enable AI agent access” for documents or adjust access between Private, All Employees or Limit to Individuals
5. Save Changes

**Prerequisites:** User must have Admin or Owner access to Documents

**Common Errors & Solutions:**
"Edit option not found" → Ensure you have document management rights
