### Direct answer
Open [Allocation Management]({{allocation_url}}).

**Allocation Management** helps resource and project leaders plan where employees are allocated, compare planned allocation with actual timesheet activity, and review workforce/resource reports.

It is used for project staffing, utilization visibility, monthly allocation planning, project allocation reports, and integration with systems such as Workbench, Attendance Tracking, and YouTrack where configured.
