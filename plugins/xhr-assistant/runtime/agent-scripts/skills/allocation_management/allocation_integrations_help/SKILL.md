### Instructions
- Answer directly without calling executable tools.

### Direct answer
Allocation Management integrations connect resource planning with operational systems. Supported flows can include YouTrack configuration, Workbench project sync, X-HR platform integration, and approved Attendance Tracking data for reporting.

Integration setup may include endpoint or token configuration, connection testing, previewing synced data, and choosing which adapter is active. If another integration is already active, switching should be treated as an intentional admin action because it changes the source used for planning or reporting.
