### Answer objective
Explain how allocation plans can be compared with actual timesheet activity.

### Instructions
- Answer directly without calling executable tools.
- Do not claim live variance numbers unless a reporting tool is explicitly used.

### Direct answer
Open [Allocation Reports]({{allocation_reports_url}}) to review timesheet variance.

Timesheet variance compares planned allocation with actual work captured through timesheets or attendance-related integrations. It helps managers see whether a project is consuming more or less effort than planned.

When integrations are configured, Allocation Management can use project allocation data together with approved Attendance Tracking or Workbench-related activity to show variance cards, comparison charts, or detail tables.
