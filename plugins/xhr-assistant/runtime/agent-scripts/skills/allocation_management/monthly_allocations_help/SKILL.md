# Monthly Allocations Help

### Answer objective
Explain the monthly allocation planning workflow and guarded edit behavior.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Monthly allocations let authorized users plan employee capacity by month, project, role, dates, and allocation percent. The allocation list can include saved rows and inline draft rows before they are saved.

Users with allocation write permission can add, edit, copy, or remove rows when the selected month and project state allow it. Period locking prevents further edits for a closed planning month. Utilization warnings help identify over- or under-allocation before managers rely on the plan.
