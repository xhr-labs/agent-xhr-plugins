# Asset Bundles Help

## Intent: asset-inventory-asset-bundles-help
### User request patterns
- explain asset bundles

- group assets into a bundle
- manage bundle membership
- find bundle details

### Retrieval tags

### Answer objective
Explain how bundles help group related assets and where users view membership.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Asset bundles group related assets so admins can review them together. Use bundle detail to see the bundle record and its asset membership.

Bundles are useful when multiple assets belong to one operational package, kit, location, or employee setup. Individual asset lifecycle rules still apply to the assets in the bundle.
