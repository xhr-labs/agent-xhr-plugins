# Asset Requests Help

## Intent: asset-inventory-asset-requests-help
### User request patterns
- request an asset
- cancel my asset request
- review asset requests
- approve an asset request
- deny an asset request

### Retrieval tags
- asset-inventory
- asset-requests
- approvals
- request-queue
- direct-answer

### Answer objective
Explain employee asset request self-service and the admin decision queue.

### Instructions
- Answer directly without calling executable tools.
- Do not imply an asset is assigned until an authorized admin decision and fulfillment step have completed.

### Direct answer
Employees use **My Requests** in Asset Inventory to create, review, and cancel their own asset requests while the request is still eligible for cancellation.

Asset managers use the request queue to review pending requests. The queue supports filtering and sorting, opening a read-only request detail, and approving or denying a request when the manager has the required permission. Approval records the decision; the actual asset assignment may still require a separate fulfillment or assignment action.
