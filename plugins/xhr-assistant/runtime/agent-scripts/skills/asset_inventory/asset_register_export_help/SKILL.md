# Asset Register Export Help

## Intent: asset-inventory-asset-register-export-help
### User request patterns

- download assets as CSV
- get a CSV of all company assets
- share inventory data with finance
- export asset inventory data

### Answer objective
Explain what the asset register export is and who should use it.

### Instructions
- Answer directly without calling executable tools.
- Do not promise a fixed column list; export content can follow the backend register contract.

### Direct answer
Asset Inventory includes an **Export CSV** action for the asset register. Authorized users can download the tenant asset register for offline review, reconciliation, or sharing with finance and operations teams.

The export is intended for inventory reporting. The exact columns follow the current asset register contract and may include asset identity, status, assignment, catalog, vendor, cost, and other managed inventory fields.
