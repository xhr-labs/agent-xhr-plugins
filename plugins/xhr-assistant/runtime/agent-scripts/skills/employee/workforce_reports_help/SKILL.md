# Workforce Reports Help

## Intent: employee-workforce-reports-help
### User request patterns
- view workforce structure reports
- check headcount trends
- compare new hires and offboarding
- report workforce by department or employee type
- filter People reports by month

### Retrieval tags
- employee
- workforce-report
- headcount
- offboarding
- analytics
- direct-answer

### Answer objective
Explain the available workforce views and filters.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Authorized Admin and HR Manager users can open **People** and switch to the **Reports** view.

The Workforce Structure report supports month, department, and employment-type filters. It includes six-month headcount, new-hire, and offboarding trends; current workforce breakdowns by department, employment type, work location, job title, and job-title type; and movement tables and charts.

An empty chart means no report data is available for the selected filter, not necessarily that the company has no employees.
