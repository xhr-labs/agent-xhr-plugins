### Direct answer
**Instructions:**
1. Go to [My Profile]({{my_profile_url}})
2. Click on the circle avatar at the top left of the page
3. Select and upload a new avatar image

*Notes:*
- Maximum file size: 5MB
- Supported formats: JPEG, PNG

**Prerequisites:** User must be logged in and accessing their own profile

**Common Errors & Solutions:** "Upload failed" → Ensure the image is under 5MB and in a supported format
"No file selected" → Select a valid image before submitting

**Follow-up Examples:** Encourage employees to personalize their profiles and explore other self-service settings available under “My Profile.”
