### Direct answer
Use the [Attendance Tracking]({{attendance_url}}) app, then open [My Attendance]({{attendance_my_attendance_url}}).

In **My Attendance**, you can add timesheet entries once you’ve been assigned to a shift by HR or an admin.

The Attendance Tracking app allows you to:
- Switch between monthly and weekly views
- See a notice if you haven’t been assigned to any shift yet
- Add and submit timesheet entries when your access and shift assignment allow it

Employees do not need to configure Reports, Shifts, Policies, rosters, or App Permissions. HR/Admin users can use [Configuration]({{attendance_configuration_settings_url}}) for setup and [App Permissions]({{attendance_app_permissions_url}}) to control access.
