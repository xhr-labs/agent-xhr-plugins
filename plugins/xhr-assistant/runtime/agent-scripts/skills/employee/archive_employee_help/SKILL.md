# Archive Employee Help

## Intent: employee-archive-employee-help
### User request patterns
- archive an employee
- remove an archived employee from the active People list
- explain archive versus terminate
- explain why I cannot archive an employee

### Retrieval tags
- employee
- archive
- lifecycle
- direct-answer

### Answer objective
Explain archive eligibility, confirmation, and the resulting People-list behavior.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Authorized HR or admin users can select **Archive** from an eligible employee's lifecycle actions and confirm the action.

After success, the employee is removed from the current active People view and no further deactivate, terminate, or archive actions are shown for that archived record. A user cannot archive their own employee record. Archive is a terminal lifecycle action; use deactivate or terminate when those states better represent the employee's situation.
