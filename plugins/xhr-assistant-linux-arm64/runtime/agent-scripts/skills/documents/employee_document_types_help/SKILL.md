# Employee Document Types Help

## Intent: employee-document-types-help
### User request patterns
- create an employee document type
- edit or delete a document type
- select a document category and type
- configure document validity dates
- explain why a document has no end date

### Retrieval tags
- documents
- employee-documents
- document-type
- effective-date
- direct-answer

### Answer objective
Explain inline document type management and effectiveness modes.

### Instructions
- Answer directly without calling executable tools.

### Direct answer
Open [People]({{people_url}}), select an employee, and open their Documents area.

When uploading an employee document, select its category and document type. Authorized users can create, edit, or delete categories and types directly from the selector.

The selected type controls date requirements:

- **None**: no effective-date fields.
- **Indefinite**: start date only.
- **Fixed**: start and end dates.

Complete any required notes and dates, then upload the file. These validity rules can also support document-expiry workflows.
