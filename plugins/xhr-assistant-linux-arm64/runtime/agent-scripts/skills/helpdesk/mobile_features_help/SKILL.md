### Direct answer
The X-HR mobile experience supports:

- Mobile Home and platform navigation
- People search, employee lists, and employee detail
- Company and employee document lists with preview for supported files
- Inbox notifications with filters and bulk actions
- Lumi chat in a mobile popover
- Time-off and other installed-app experiences when their mobile routes are available

Available screens depend on the user's permissions and the applications installed for the company.
