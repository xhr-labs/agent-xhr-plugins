### Direct answer
**Instructions:**
1. Go to [Documents]({{documents_url}})
2. Find the document listed by name
3. Sort by category, upload date or uploaded by to make it easier
4. Select your desired action from the available options (Download, Edit Details & Access Permissions or Delete)

**Prerequisites:** User must have the right permission to view the documents

**Common Errors & Solutions:**
"Document not found" → Ensure you have document management rights
