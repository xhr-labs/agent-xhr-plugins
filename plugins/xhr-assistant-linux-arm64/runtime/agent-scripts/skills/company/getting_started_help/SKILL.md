### Direct answer
Start by going to [Workspace -> Company Profile]({{company_account_url}}).

Here, you can configure your company’s basic information, including:
- Company size
- Industry
- Headquarters location
- Contact details

From the same workspace area, you can also manage:
- Work locations
- Custom fields
- Default currency
- Holiday calendars

These settings help tailor X-HR to match how your organization operates.
